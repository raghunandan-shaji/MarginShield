# Legacy artifacts

This directory contains broad-refund-abuse experiments and early source-research
files retained for provenance. They are not loaded by the active MarginShield API,
training pipeline, or UI.

The active model is `data/model/live_refund_ring_model.joblib`; the active report is
`data/reports/ring_model_report.json`; and the active target is `ring_label` for
coordinated refund-abuse rings only.
